# Sistema de Automatización de Inventario de Dispositivos de Red

## Descripción

Proyecto de automatización desarrollado con Python para procesar y analizar información de dispositivos de red.

El sistema permite trabajar con archivos JSON, CSV y YAML, realizar un análisis del inventario y consultar una API REST mediante HTTPS.

## Tecnologías utilizadas

- Linux
- Python 3
- Git
- JSON
- CSV
- YAML
- REST API
- HTTPS
